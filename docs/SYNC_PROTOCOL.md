# 同步协议 v1

## 1. 范围

单个人、一个服务端工作区、多台设备。不是多人实时协作，不支持把同一客户端无提示切换到任意服务器。服务端可以读取正文；没有端到端加密。

UI 手动同步。令牌只在设置页内存，离开设置后需重新填写。服务地址需要 HTTPS；仅 localhost 回环调试允许 HTTP。

## 2. 接口

所有 `/v1/*` 接口要求 `Authorization: Bearer <token>`；healthz 不返回敏感信息。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /healthz | 存活检查 |
| GET | /v1/info | 协议版本与 serverId |
| POST | /v1/sync/push | 提交最多 100 个待同步操作 |
| GET | /v1/sync/pull?serverId=...&cursor=... | 分页读取变更，默认 200 条 |
| GET | /v1/openapi.json | 受认证保护的 OpenAPI 描述 |

push 请求：

```json
{
  "serverId": "工作区 UUID",
  "operations": [
    { "opId": "随机 UUID", "baseVersion": 3, "doc": "完整文档对象，不是字符串" }
  ]
}
```

这里是协议形状示意；真实 doc 必须是满足 JSON Schema 的对象，真实 UUID 必须合法。

push 响应每个操作包含 opId、status（accepted/conflict）、doc。accepted 文档 version 为旧值加一；conflict 返回当时远端记录。

pull 响应包含 serverId、changes（seq + doc）、cursor、hasMore。

## 3. 一次同步

1. 在本机串行化这次同步和编辑，读取当前工作区。
2. 检查协议与 serverId，拒绝意外更换服务器。
3. 复制待上传批次，发送 opId + baseVersion + doc。
4. 接受确认或登记冲突；尚未持久化确认前 outbox 不变。
5. 从 cursor 分页拉取变更；待上传或冲突中的文档不直接覆盖。
6. 一次本地原子提交保存全部结果、outbox 变化、冲突与新 cursor。

另一标签页在此期间写入会导致最终 CAS 失败。已上传操作仍在旧 outbox 中，下次通过幂等重试恢复，而不是重写另一标签页的数据。

## 4. 幂等性

操作 ID 的请求内容不可变。服务端保存规范化请求 hash 与结果。同一个 opId 传来不同内容，返回 409，并回滚该批事务。

服务端已经写入但响应丢失：客户端保留原 outbox，重试得到原确认，不增加重复 change-log 记录。

在未收到确认前，用户又修改同一文档：生成新 opId，保留旧 baseVersion。若旧操作其实已到服务端，下一次会出现保守冲突，不会静默丢失新编辑。

## 5. 冲突与删除

两个设备基于同一版本修改同一文档，先被接受的写入成功，另一个得到冲突。这里“先被接受”是数据库版本比较的结果，不依赖不可信的设备时钟。

当前人工选择本机或远端版本，双方副本保留在历史。整篇论文为冲突单位；两个设备改同一论文的不同小字段也会冲突，这是为了换取实现简单与历史一致性。

删除也有版本与 tombstone。旧设备离线编辑已删除记录时应冲突，不能自动复活。暂不回收 tombstone 和幂等操作表；公开版本需加入设备确认边界与压缩方案。

## 6. 服务端恢复

物理备份通过 SQLite backup API。恢复旧备份前停止服务，验证完整性，轮换 server_id，让旧客户端显式停止同步。不能用复制旧数据库、保持同样 ID 的方式假装没有回滚。

客户端便携备份恢复不保留 serverId 或 cursor。连接已有服务端时，如对象 ID 已存在，会产生冲突而不是静默替换。批量对账与恢复向导尚未实现。

## 7. 协议限制

请求最多5MB；单文档紧凑JSON按UTF-8最多500000字节（服务端版本递增后再次校验）；每批最多100操作。客户端按完整请求UTF-8字节限制每轮上传≤4MB/100条，余项保留outbox，需再次同步。服务端不提供注册、设备级撤销、限流或端到端加密。

客户端核对info工作区标识、ACK身份/版本/正文、下载seq严格递增及cursor对应关系，异常整轮不提交。本轮仍全程持有业务写队列，下载最多100页（默认200条/页）；更长历史追赶的检查点设计尚未实现，见ARCHITECTURE_REVIEW。

服务端 JSON Schema 严格拒绝未知字段。客户端校验和服务端校验尚未完全代码生成；契约测试是当前保护，不代表完成了形式化验证。
