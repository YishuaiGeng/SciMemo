# 已知限制：开发版验收边界

更新：2026-10-14（三轮）。完整TypeScript检查、分层校验（25文件/89导入/0违规）、Web构建、141项核心测试（含27项读模型、21项错误模型、15项存储故障）、58项后端测试与临时服务真实HTTP集成已实测。详见 [TEST_REPORT](TEST_REPORT.md)。

## 本轮已解决

- **搜索匹配字段名**：`searchDocs` 原用 `JSON.stringify(d.data)`，搜 "title" 会命中全部稿件。已改为只遍历字段值，并新增 `kinds` 过滤。
- **计数混算**：页脚与侧边栏原用 `Object.values(ws.docs).filter(d=>!d.deleted).length`，把四类记录混成一个数字。已改为 `core/read/stats.ts` 的按类型计数。
- **领域层直接读时钟与随机源**：`domain.ts` 的 `now()`/`uid()` 使时间相关行为无法断言。已引入可注入的 `Context`；`makeDoc`/`addSubmission`/`addSubmissionEvent` 接受可选 `Context`。
- **分层规则无法校验**：新增 `scripts/check-layers.mjs` 并纳入 `npm run check`，已用注入违规验证其有效性。
- **缺"该我动作"视图**：新增 `AgendaView` 与派生读模型（`core/read/`）。
- **错误无法分类**：UI 原先只有"成功/失败"二元组，无法区分可重试与不可重试、数据未保存与数据完好。已引入 `core/errors.ts` 的 11 个错误码与 `ui/messages.ts` 的呈现映射；存储失败与同步协议错误为持久提示。
- **`window.confirm`**：删除确认与放弃编辑确认改用自有 `ConfirmDialog`（原生 `<dialog>`，焦点默认在安全选项）。
- **保存失败会关闭编辑器**：`saveCommand` 吞掉错误导致 `onSave` 总是成功、编辑器照常关闭、输入丢失。已改为失败时保持打开。
- **`importBackup` 泄漏原生 `SyntaxError`**：损坏的 JSON 文件会抛出未分类错误。已就地分类为 `IMPORT_FORMAT`。
- **`STORAGE` 码未经触发**：已用可复现的 IndexedDB 替身覆盖配额、提交中止、连接关闭、打开失败与升级阻塞；同时修掉 `TauriDriver` 把修订号冲突误报为存储失败的问题。
- **偶发失败测试**：`error-model.test.mjs` 有一项用 `new Date()` 生成变更后的 `createdAt`，可能与 `makeDoc` 落在同一毫秒而随机失败；已改为固定时间戳。
- **仓库内开发残留**：删除 3 个 `.DS_Store` 与 2 个 `__pycache__`。

## 仍未解决

1. 浏览器交互与IndexedDB持久化未验收。读模型测试运行在普通对象构造的工作区上，不涉及真实存储。
2. **Rust 已在 macOS arm64 上编译通过并启动窗口**（第四轮）；6 项原生存储测试覆盖重启持久化与回滚。**Windows 未编译**（只能交给 CI，而仓库尚无 `.git`）；桌面窗口内的端到端交互、安装包、签名、公证与更新均未验证。Android/iOS 未初始化。
3. 整工作区持久化尚无增量提交、FTS与性能基线；原生工作区上限30MB。SQLite 多次读取已包进同一读事务（第四轮）。
4. 浏览器不是完整PWA，无Service Worker与manifest，不保证断网冷启动；清理站点数据会影响预览工作区。**可安装PWA（SM-020）尚未开始。**
5. 同步仅手动，每轮上传最多100条/4MB，余项需继续同步。网络期间持有业务写队列；下载上限100页，长历史检查点追赶未实现。
6. 同步为单工作区共享令牌，无端到端加密、设备级授权、后台退避、服务限流或日志压缩。冲突按整篇稿件/整条记录保留双方，无字段级自动合并。
7. 无附件、自动备份、异常退出草稿恢复、原生另存为或后台通知。原生导出已改为系统另存为对话框 + 临时文件写完后原子改名（第四轮），但未在窗口中实际点击验证。**静默阈值仅在当前会话内存中，未持久化。**
7b. **`STORAGE` 路径已用替身验证，但未在真实存储上验证**。`tests/fake-indexeddb.mjs` 复现了配额耗尽、提交时中止、连接被另一标签页关闭、打开失败与升级阻塞，驱动分类、失败原子性与呈现文案均有断言（SM-028）。但替身是按规范行为建模的，**真实浏览器的配额耗尽、真实磁盘满与真实 WAL 提交失败仍未测试**。另：Rust 侧未编译，`LOCAL_CONFLICT:` 前缀契约只由源码级测试固定，Cargo 编译后需复验。
7c. **驱动仍无真实浏览器交互测试**。`fake-indexeddb.mjs` 是测试替身，不能被表述为"IndexedDB 已验收"。第 1 条的限制仍然成立。
7b. **`STORAGE` 错误码未经真实触发验证**。驱动层已把 IndexedDB 配额耗尽／被阻塞、Tauri invoke 拒绝标注为 `STORAGE`，但没有制造过真实存储故障，因此"存储失败时用户看到持久警告且明确知道未保存"这条承诺**尚未被验证**。这是当前最需要真实环境验证的一项。
8. 已有届次编辑、投稿元信息补填、事件纠错/撤销、独立补录历史、批量恢复与显式候选优先级调整UI未实现。终态误录无法正常纠正。
9. 日程仅关联稿件，不能精确绑定某次投稿/修回轮次。**读模型的静默提醒无法区分"投稿后无回音"与"刚投稿尚未到编辑处理"，二者共用同一 21 天阈值。**
10. 精确时间未检查UTC偏移与该日期IANA时区的一致性；JS/Python的时区别名与固定偏移接受范围可能不同。
11. Schema与双端语义仍需共同维护。**当前数据模型要求字段集合完全相等（`shape()` 与 `additionalProperties:false`），因此不存在"兼容地新增可选字段"——任何字段变更都是破坏性变更，必须走迁移。** 迁移框架本身尚未实现。
12. `Cargo.lock` 已生成并在 CI 使用 `--locked`；依赖漏洞审计（npm 与 cargo）未完成。远端CI未执行。
13. 导入只允许全新空工作区。同步和备份不含附件。
