# 里程碑与 GitHub Issue 拆分

不要按“完成多少页面”判断进展，而要按数据闭环与真实设备验收。

## M0：当前开发脚手架

代码已有核心业务、响应式React页面、本地适配器、原生壳和私有同步服务。本轮完整TypeScript检查、Web构建、78项核心/58项后端与隔离HTTP集成通过；浏览器交互、原生和设备仍待验收，见TEST_REPORT。流程缺口与架构取舍见RESEARCH_WORKFLOW_REVIEW和ARCHITECTURE_REVIEW。

## 扩展候选，但不是首版承诺

用户粘贴邮件后辅助提取状态；从官方来源手动导入会议资料；期刊信息核查记录；可选端到端加密。AI 不作为保存／读取资料的依赖。

## 不进入近期路线

文献引用库、PDF 阅读器、多人科研绩效系统、教师学生管理、实验集群调度、通用低代码数据库、插件市场。

## 公开发布验收底线

真实设备重启后数据存在；断网可编辑；转投不会覆盖旧历史；两端冲突不会无提示覆盖；空工作区能恢复备份；错误日期不会被系统“纠正”为虚构事实；关闭同步后无网络上传；敏感数据不进入日志和仓库。
